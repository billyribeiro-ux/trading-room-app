# Contributing

The repository's normative engineering standard is
[`docs/ENGINEERING-SSOT.md`](docs/ENGINEERING-SSOT.md). Read it before proposing or
implementing a change.

Minimum local verification:

```bash
pnpm install
pnpm quality
```

Pull requests must explain the behavior changed, evidence used, risks and trust
boundaries considered, tests added, and any verification that could not be run.
Use the pull-request template; do not mark an unchecked gate as passing.
